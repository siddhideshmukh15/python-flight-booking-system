✈️ Python Flight Booking System

A simple Python-based Flight Booking System that allows users to view available flights, book tickets, and check the total booking price.

Features

- View available flights
- Display ticket prices and available seats
- Book multiple tickets
- Enter passenger name
- Calculate total booking cost
- Automatically update available seats
- Exit the system

Concepts Used

- Python Dictionaries
- "while" loop
- "for" loop
- "if-elif-else"
- User Input
- Arithmetic Operations
- Dictionary Access and Updating
